# Supermarket Website Mockup

A clean, modern supermarket / grocery e-commerce website mockup.

**Developer:** Eminem Mwaniki Moni  
GitHub: [monieminem](https://github.com/monieminem)

---

## Features

- Responsive homepage with hero banner
- Category navigation
- Product grid with prices, badges & add-to-cart buttons
- Sticky header + simple cart counter
- Mobile-friendly design
- Built with plain HTML, Tailwind CSS (CDN) and vanilla JavaScript

## How to view

Just open `index.html` in any browser, or serve the folder:

```bash
npx serve .
# or
python -m http.server 8000
```

## Structure

```
supermarket-mockup/
├── index.html          # Main page
├── styles.css          # Extra custom styles
├── script.js           # Cart counter & interactions
└── README.md
```
